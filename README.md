# Logistics Route Optimization Planning

## Objective
This repository contains the strategic planning pseudocode and structural outline for a logistics data analysis project focused on last-mile delivery optimization. 

## Project Overview
The goal is to transition a regional e-commerce distribution center from static routing to dynamic, data-driven routing to reduce driver fatigue and fuel consumption.

**Key Performance Indicators (KPIs) Tracked:**
* Average Fuel Cost per Route
* On-Time Delivery Rate (OTDR)
* Vehicle Utilization Rate

## Methodology
The proposed analytical approach utilizes:
1. **K-Means Clustering:** To geographically group delivery zones.
2. **Vehicle Routing Problem (VRP) Algorithms:** To determine the shortest sequence of stops.
3. **Exploratory Data Analysis (EDA):** To identify temporal bottlenecks in delivery schedules.

## Files
* `route_optimization_eda.py`: Python script illustrating the data cleaning and K-Means clustering phases of the strategic plan.
